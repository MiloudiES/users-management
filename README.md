# 🏢 Employee Management System

A lightweight, responsive CRUD (Create, Read, Update, Delete) application built with **Vanilla JavaScript** and **Bootstrap 5**. This project demonstrates how to interact with a RESTful API to manage employee data in real-time.



## ✨ Features

* **Live Data Fetching:** Automatically retrieves a list of employees from the JSONPlaceholder API on page load.
* **Create Records:** Add new employees via a structured form using `POST` requests.
* **Dynamic Table Rendering:** The UI updates instantly when users are added, edited, or deleted without requiring a page refresh.
* **Full CRUD Support:**
    * **Create:** `POST` new user data to the server.
    * **Read:** `GET` user list and display in a Bootstrap table.
    * **Update:** `PUT` changes to existing records via interactive prompts.
    * **Delete:** Remove users from the local state and UI.
* **Responsive Design:** Styled with Bootstrap 5 for a clean, mobile-friendly experience.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Scripting:** Vanilla JavaScript (ES6+)
* **API:** [JSONPlaceholder](https://jsonplaceholder.typicode.com/)
* **Asynchronous Handling:** `Async/Await` & `Fetch API`
